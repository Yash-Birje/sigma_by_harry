CSS Units

Each div below has one para and each div uses the different units

This div is using px (pixels) as its font size and a border of 3px

This div is using em (relative to the font-size of the element) as its font size and a border of 3em

This div is using rem (relative to the font-size of the root element) as its font size and a border of 3rem

This div is using % (percentage) as its font size and a border of 30%. But it is not as commonly used for layout as the other units.

This div is using vmin (viewport minimum) as its font size and a border of 3vmin

This div is using vmax (viewport maximum) as its font size and a border of 3vmax

This div is using vw (viewport width) as its font size and a border of 3vw

This div is using vh (viewport height) as its font size and a border of 3vh
